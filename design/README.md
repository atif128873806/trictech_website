# Design review assets

The editable [Figma file](https://www.figma.com/design/KLC6xLAlHz0GzwG3ggLjLg) contains red/white/neutral foundations, IBM Plex Sans styles, desktop pages, mobile and tablet screens, inquiry states, sitemap, wireframes, and service-discovery prototype links. The project owner moved the project into development on 2026-09-16 using this work as the visual baseline.

These SVG boards preserve the design compositions used for implementation. PNGs are rendered previews for quick visual inspection; the SVGs preserve vector resolution.
